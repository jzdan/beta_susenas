Sesudah 13 menu

  • Kotak "Triwulan berjalan": 1 klik ke hub yang sedang aktif
  • Periode Survei: tahun → triwulan → hub
  • Dashboard, Tugas Saya, Peta Progres, Daftar Sampel, Pengolahan, Tabulasi, Indikator, Kinerja Tim, Log Audit (tetap, untuk kerja harian lintas triwulan)
